# 003 プロセスの所有と安全な停止

起動完了は、自分の PID を返す rc と、マウント先の存在の両方で判定する。
状態ファイルは PID・起動時刻・実行ファイルを持ち、停止対象を照合する。
名前付きミューテックスで操作を直列化し、キャッシュにも所有 PID を残す。異なる設定からの重複利用も防ぐため。
Core は同期 API とし、スレッドに属するミューテックスを await の前後に持ち越さない。
通常停止と再接続は uploadsQueued / uploadsInProgress が 0 のときだけ行う。件数が不明でも拒否する。
状態と設定ファイルの対応も照合し、別の設定による稼働中のマウントの置き換えを防ぐ。
状態取得は起動・停止と直列化する。起動完了前の状態を見て試験がプロセスを落とした競合が、実測で見つかったため。
ネットワーク共有名はマウントとキャッシュから決めた固有名にする。既存マウントの既定共有名と衝突した実測が理由。
